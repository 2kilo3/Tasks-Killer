# 文档路线

这些路线都是可选的。任务和已确认意图决定要不要文档、要哪种格式。没有一条路线是必经的。缺能力时交已完成的部分，并写明缺什么。不要为了走某条路线去安装整套办公软件。

| 要做的事 | 可用路线 | 边界 |
| --- | --- | --- |
| 改普通办公文档副本 | 已安装的编辑器、LibreOffice，或 Python 与 `python-docx` | `python-docx` 不是页面渲染器。保存后要重开 |
| 核对目标编辑器里的模板 | 该模板实际使用的编辑器版本 | 桌面自动化只在那个系统提供它时可用。别的系统没有同一条路 |
| 导出 PDF 供看页面 | 编辑器导出，或 `soffice --headless --convert-to pdf` | 替代引擎的预览不能说成目标编辑器的结果 |
| 逐页看 | 本机 PDF 查看器，或 `pdftoppm` / PyMuPDF | 抽出文本不等于看过页面 |

字体从当前模板读。缺字体就报告，不把另一套字体当成模板要求。替代字体可能改换行和分页。

预检只查这一次要用的路线：输入能读、输出能写、原模板没被改。工具失败时先看路径、占用、权限和字体，再按新依据重试。
